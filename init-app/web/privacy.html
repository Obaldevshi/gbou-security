Политика конфиденциальности

Обновлено 16 августа 2026 года.

«Система учета выхода учащихся» предназначена для уполномоченных сотрудников образовательных организаций. Система обрабатывает сведения об учётных записях, классах, учащихся и заявках на выход только для организации безопасного выхода учащихся.

Данные разделены по школам и доступны только пользователям с соответствующей ролью. Пароли хранятся в виде криптографических хешей, передача выполняется по HTTPS. Данные не продаются и не используются для рекламы.

Для исправления или удаления данных обратитесь к администратору своей школы.
