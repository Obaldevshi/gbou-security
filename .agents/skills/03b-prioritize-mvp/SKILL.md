# Приоритизация MVP

1. Прочитать `artifacts/feature-map.md`.
2. Оставить только функции, необходимые для одного сквозного полезного сценария.
3. Перенести остальное в раздел «Позже» без реализации.
4. Для каждой оставшейся функции указать причину включения и зависимость.
5. Обновить `artifacts/feature-map.md` и создать начальную очередь `artifacts/features/_queue.md`.
6. Перейти к `$04-map-screens`.
