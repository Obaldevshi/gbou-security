# Пользовательские истории

1. Выбрать только неоднозначную функцию из очереди.
2. Записать истории в формате «Как пользователь, я хочу…, чтобы…».
3. Добавить проверяемые критерии приёмки, ошибки и граничные случаи.
4. Не описывать детали реализации.
5. Сохранить результат в `artifacts/user-stories.md` или карточке функции.
6. Вернуться к вызвавшему шагу.
