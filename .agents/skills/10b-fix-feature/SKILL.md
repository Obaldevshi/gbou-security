# Исправление функции

1. Зафиксировать воспроизводимый симптом и ожидаемое поведение.
2. Найти минимальную первопричину по логам, трассировке и контракту.
3. Внести минимальное исправление без несвязанных рефакторингов.
4. Добавить или уточнить регрессионный сценарий в коде либо в ручном чек-листе.
5. Не запускать приложение, UI-проверки, анализатор, тесты и сборки без отдельной явной просьбы. Передать затронутый и регрессионный сценарии пользователю для повторной проверки.
6. Обновить карточку функции и вернуться к `$11-verify-mock` или `$13-check-api-timeweb` согласно источнику дефекта и результату, который сообщит пользователь.
