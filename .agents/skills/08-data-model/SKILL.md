# Модель данных

1. Выделить сущности, обязательные поля, типы, ограничения и связи.
2. Сопоставить модели FastAPI/Pydantic, таблицы SQLAlchemy и DTO Flutter.
3. Описать запросы, ответы, ошибки и правила пагинации.
4. Учитывать существующие соглашения репозитория.
5. Записать результат в `artifacts/data-model.md` или карточку функции.
6. Вернуться к вызвавшему шагу.
