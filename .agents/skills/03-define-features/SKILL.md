# Карта функций

1. Прочитать `artifacts/idea-brief.md`.
2. Извлечь функции из импортированной идеи, не расширяя исходный объём.
3. Для каждой функции указать пользователя, сценарий, данные, адаптивные экраны mobile/web и API-операции.
4. Сохранить приоритеты из исходного файла; если их нет, явно отметить это без самостоятельного выбора.
5. Записать результат в `artifacts/feature-map.md`.
6. При слишком большом объёме вызвать `$03b-prioritize-mvp`, иначе перейти к `$04-map-screens`.
