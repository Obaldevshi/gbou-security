# Визуальное направление

1. Определить основные цвета, контраст светлой/тёмной темы, типографику, интервалы и радиусы.
2. Менять централизованные токены в `init-app/lib/app/theme/`.
3. Не дублировать значения в отдельных виджетах без необходимости.
4. Для wide-компоновки ограничивать ширину контента; для narrow сохранять удобные touch-цели и работу с клавиатурой.
5. Не добавлять blur и тяжёлые эффекты;
6. Записать решения в `artifacts/app-config.md`.
7. Перейти к `$09-plan-features`.
