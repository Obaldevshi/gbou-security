# Планирование функции

1. Прочитать `artifacts/features/_queue.md` и выбрать первую незавершённую функцию без блокеров.
2. Проверить готовность поведения и данных; при пробелах вызвать `$07-write-stories` или `$08-data-model`.
3. Создать или обновить `artifacts/features/<feature>.md`.
4. Указать изменения backend, общего Flutter-кода mobile/web, адаптива, генераторов и проверок на обеих целях.
5. Ограничить итерацию одной функцией.
6. Если очередь завершена, перейти к `$13-check-api-timeweb`; иначе — к `$10-add-feature`.
