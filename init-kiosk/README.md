# Пост охраны на Raspberry Pi 3

Отдельный лёгкий kiosk-клиент. Он не использует Flutter, npm, CanvasKit и
сторонние web-библиотеки. До входа видны только авторизация охранника,
виртуальная клавиатура и настройка Wi-Fi. После входа доступны очередь,
история и действие «Отпустить».

## Требования

- Raspberry Pi 3 с Raspberry Pi OS Bookworm Desktop;
- сенсорный экран 7–10 дюймов;
- NetworkManager (`nmcli`), Python 3 и Chromium;
- отдельная учётная запись охранника, привязанная к нужному корпусу.

## Установка

Скопируйте каталог `init-kiosk` на Raspberry Pi, затем выполните:

```bash
sudo apt update
sudo apt install -y python3 network-manager chromium
cd init-kiosk
chmod +x scripts/install.sh scripts/chromium-kiosk.sh
sudo GBOU_API_BASE=https://obaldevshi-gbou-security-ac8a.twc1.net/api/v1 \
  ./scripts/install.sh "$USER"
sudo reboot
```

Если в вашей версии ОС пакет называется `chromium-browser`, установите его
вместо `chromium`. Скрипт запуска поддерживает оба имени.

## Работа

- локальный интерфейс: `http://127.0.0.1:8765`;
- проверка сервиса: `http://127.0.0.1:8765/health`;
- вход разрешён только пользователям с ролью охранника;
- очередь обновляется каждые 3 секунды без наложения медленных запросов;
- список прокручивается вертикальным жестом по карточкам без выделения текста;
- нажатие «Отпустить» сразу скрывает заявку без дополнительного подтверждения;
- Wi-Fi настраивается кнопкой на экране входа или в шапке очереди;
- токен хранится в памяти вкладки и удаляется после закрытия Chromium/выхода.

## Автоматические обновления

После установки киоск раз в 5 минут проверяет
`https://gbousecurity.ru/kiosk/manifest.json`. Новая web-часть скачивается во
временный каталог, каждый файл проверяется по размеру и SHA-256, а затем
атомарно заменяет локальную копию. Открытая страница сама перезагружается не
позднее чем через минуту и сохраняет сессию охранника в `sessionStorage`.

Если сайт или интернет недоступны, киоск продолжает работать на последней
успешно сохранённой версии. Для публикации новой версии после изменения файлов
в `init-kiosk/web` выполните `python init-kiosk/scripts/publish_web.py`, затем
опубликуйте изменения сайта. Файлы появятся в `/kiosk`; полная пересборка
Flutter для изменения только киоска не требуется.

Автоматически обновляется только HTML/CSS/JavaScript. Системный Python-сервис,
права NetworkManager и Chromium обновляются отдельным установочным пакетом.

## Обновление адреса API

Измените `/etc/gbou-kiosk.conf`:

```dotenv
GBOU_API_BASE=https://адрес-api/api/v1
GBOU_KIOSK_UPDATE_BASE=https://gbousecurity.ru/kiosk
```

После изменения выполните:

```bash
sudo systemctl restart gbou-kiosk
```

## Диагностика

```bash
systemctl status gbou-kiosk --no-pager
journalctl -u gbou-kiosk -n 100 --no-pager
nmcli device wifi list
curl http://127.0.0.1:8765/health
```

Локальный сервис слушает только `127.0.0.1`, поэтому управление Wi-Fi не
доступно другим устройствам сети.
