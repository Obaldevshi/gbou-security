GBOU Security 1.7.0+12

Внутренний кандидат для проверки, не версия с подтверждённой модерацией.

  1. Подробный отчёт и требования RuStore, Google Play, App Store.
  2. Подписанный APK для внутренней проверки Android. Подпись постоянная, не debug.
  3. Android App Bundle — кандидат для Google Play, не файл установки на телефон.
  4. Снимки синтетических проверок: artifacts/visual-audit-cross-store/ и artifacts/visual-audit-store/. Сохраните структуру папок после распаковки.

Новые удаление аккаунта и политика ещё не опубликованы на рабочем backend. Перед обычным использованием кандидата требуется согласованный выпуск совместимого сервера; не проверяйте удаление на рабочих учётных записях. Для новой установки сначала укажите школьный HTTPS-адрес через «Подключение к школе»; для безопасной проверки без сервера используйте «Демонстрация».

Комплект iOS с исходниками

Архив gbou-security-ios-source-1.7.0-12.zip содержит Flutter lib/assets/ios и инструкции, но не IPA, ключи подписи, backend и базу школы. На Mac распакуйте отдельно, установите Flutter и Xcode, выполните bash tools/build_ios_candidate.sh. Затем настройте собственный Team и подпись в Xcode, проверьте iPhone/iPad, privacy report и TestFlight. Не переносите чужой Team без проверки принадлежности.

Окончательная политика, правовые основания, SDK-диагностика, права на шаблон и магазинные декларации требуют реального решения владельца. Во время подготовки соглашения не принимались, платные услуги не создавались, рабочие данные не удалялись.
