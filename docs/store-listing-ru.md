# Карточка приложения

## Название

Безопасность ГБОУ

## Краткое описание

Заявки на безопасный выход учащихся для учителей и школьной охраны.

## Полное описание

«Безопасность ГБОУ» объединяет учителей, администрацию и охрану школы в одном
защищённом рабочем пространстве. Учитель создаёт разрешение на выход ученика,
охранник видит его без бумажных записок и подтверждает фактический выход.
Администрация управляет классами и учётными записями, контролирует историю,
отчёты и журнал действий. Данные каждой школы изолированы.

Регистрация отсутствует: доступ выдаёт администратор образовательной организации.
