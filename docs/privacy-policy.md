# Политика конфиденциальности «Безопасность ГБОУ»

Дата обновления: 16 августа 2026 года.

Приложение предназначено для уполномоченных сотрудников образовательных
организаций. Оно обрабатывает данные учётных записей сотрудников, сведения о
классах и учащихся, а также историю заявок на выход исключительно для
организации безопасного выхода учащихся.

Данные разделены по школам и доступны только пользователям с соответствующей
ролью. Пароли хранятся только в виде криптографических хешей. Тела форм и пароли
не записываются в журнал аудита. Передача выполняется по HTTPS.

Данные не продаются и не используются для рекламы. Срок хранения определяется
образовательной организацией и требованиями законодательства. Для исправления
или удаления данных следует обратиться к администратору своей школы.

По вопросам конфиденциальности: администратор информационной системы вашей
образовательной организации.
