# Готовность подготовки — 09.10.2026

Подготовлены локальный школьный API на SQLite, зашифрованные USB-копии,
защищённый перенос одной школы, синхронизация корпусов/администраторов,
локальный web, Android с выбором школьного HTTPS-узла, инструкции установки.
Школьный администратор видит состояние USB, SD и дату проверенной копии.

## Выполненные проверки

- 89 серверных тестов, включая настоящие временные SQLite и AES-GCM.
- 24 Flutter-теста: существующие сценарии и изоляция соединений/сессии/PIN.
- Flutter analyzer: без замечаний.
- Flutter release web с `GBOU_LOCAL_MODE=true`: собран.
- Android APK 1.4.0+8: собран, подпись проверена.
- Alembic: единственный head `010_school_node_credentials`.
- Linux-сценарии: синтаксис проверен, на Raspberry не запускались.

APK подписан имеющимся **Android Debug** ключом для предварительной проверки.
Для RuStore требуется отдельная release-подпись; закрытый ключ в этом
окружении не задан. Не заменять им ключ уже опубликованного приложения.

## Что не выполнялось

Установка на Raspberry, подключение USB, реальное тестирование TLS,
перенос школьных записей, остановка сервиса школы, очистка облачной базы,
публикация/деплой, push. Старый сайт продолжает работать без переключения.
Все проверки используют синтетические данные и не читают production-базу.

## Порядок следующего этапа

1. Получить SSH, проверить архитектуру ОС, имя и сеть Raspberry, свободное
   место, фактические носители и питание.
2. Установить API и web по README, настроить TLS/устройства по CLIENTS.
3. Проверить монтирование отдельной USB и сохранить пароль копий вне Pi.
4. Применить центральную миграцию, выдать ключ ровно нужной школе.
5. Для действующей школы пройти CUTOVER целиком; для новой без старых данных
   можно `enroll-empty`. До проверки существующей школы не включать cloud.

Процесс переноса не доказывает соблюдение требований к обработке данных сам
по себе. Рабочая SD пока не зашифрована; нужны физическая защита, регламент
доступа и отдельная проверка шифрования/хранения резервных копий.
