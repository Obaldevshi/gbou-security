# E16 — публичная страница проекта

Статус: реализовано, ожидает публикации web-сборки.

## Маршрут

- `/about/` — статическая русскоязычная страница без авторизации.
- `/#/login` — переход в рабочую систему.

## Состав

- задача школ и схема работы заявки;
- преимущества для учителя, охраны, администратора школы и главного администратора;
- Android, адаптивная web-версия и Raspberry Pi kiosk;
- демонстрационные скриншоты без персональных данных;
- безопасность и границы решения;
- FAQ, вход в систему и контакт администратора.

## Контакт

Контакт не зашит в приложение. Он задаётся в
`init-app/web/about/contact-config.js` одним из полей `email`, `telegram` или
`phone`. Пока значение не задано, страница не публикует вымышленный адрес и
показывает нейтральное уведомление.

## Приёмка

- страница читается на ширине от 320 px;
- доступна клавиатурная ссылка перехода к содержимому;
- изображения загружаются лениво;
- метаданные страницы полностью русские;
- рабочее приложение не загружается при просмотре страницы `/about/`.
