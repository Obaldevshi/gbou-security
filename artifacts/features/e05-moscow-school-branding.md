# E05 — Стиль московского образовательного портала

## Цель

Переименовать пользовательский интерфейс в «Система учета выхода учащихся» и
перевести mobile/web на спокойную официальную сине-бирюзовую палитру,
характерную для образовательных порталов московских школ.

## Изменения

- единое название в Flutter, web-заставке, HTML metadata, Android и iOS;
- централизованная палитра в `AppColors` без дублирования цветов по экранам;
- светлая тема по умолчанию для новых пользователей;
- сохранение ранее выбранной пользователем темы;
- обновлённая тёмная тема в тех же сине-бирюзовых тонах;
- backend, роли, маршруты и API-контракты не изменяются.

## Адаптивность

- существующие narrow/wide-компоновки сохраняются;
- размеры touch-целей и максимальная ширина форм не меняются;
- длинное название допускает перенос строки на narrow-экранах.

## Проверки

- генерация локализаций;
- Flutter analyzer;
- проверка отсутствия старого названия в пользовательских поверхностях;
- ручная проверка контраста, переноса заголовка и обеих тем после сборки.

## Результат

- локализации сгенерированы;
- Flutter analyzer завершён без замечаний;
- production web build завершён успешно;
- основной JS после gzip: 989758 байт;
- сохранены 10 отложенных ролевых чанков и их gzip-версии;
- версия CDN/service-worker кеша обновлена до `1.1.0-8`.
